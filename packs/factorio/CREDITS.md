## Game data (`data/`)

Generated by the pack's importer (`plugin/importer.ts`) from the game's own data. We have no game install, so every file below is a copy found in a public repository.

### Items, fluids, buildings, recipes, belts, pipes and resources

- **Source:** Factorio **2.1.14** with Space Age (the built-in mods `base`, `core`, `elevated-rails`, `quality`, `recycler` and `space-age`, no other mods), the output of `factorio --dump-data` (`script-output/data-raw-dump.json`). The copy used is `static/data-raw-dump.json` (13,679,605 bytes, SHA-256 `7851bac96e1f4217e60e8e242c6b5e835f05acb9d7f9f9ca5d68e9286013d307`) in [alecraso/factorio-mcp-server](https://github.com/alecraso/factorio-mcp-server) at commit `e8ae8606c8d01519b22ae9335d11c435e31dbaf5` (2026-08-11). Its `static/meta.json` records version 2.1.14, no mods and a dump date of 2026-08-06; its `static/README.md` says it was dumped from an owned install and written back compactly, otherwise unchanged.
- **Terms:** © Wube Software. The repository's MIT licence (© 2026 Aaron Biller) covers its code; its README bases redistributing the dump on Wube publishing the same prototype data in [wube/factorio-data](https://github.com/wube/factorio-data) "to help mod authors".
- **Checked against:** the Lua prototypes in [wube/factorio-data](https://github.com/wube/factorio-data) at tag `2.1.14` (commit `a78495471dfbe7848c9c7be752e32f5065e072cb`): machine crafting speeds and energy use, and belt speeds. All 612 recipes (times, ingredients, products and machines) and the item names also match FactorioLab's Factorio 2.1.20 Space Age data (`public/data/2x1/data.json`, see the icons below).
- **Pipe throughput** (6000 per second) isn't in the data; it's the most one fluid connection passes in the 2.x fluid system, as the [Factorio wiki's pump page](https://wiki.factorio.com/Pump) states. Belt colours ("yellow belt" …) are common knowledge.
- **In this repository:** only the generated data and a small excerpt of the dump and the locale, as the importer's test fixture (`plugin/importer.fixture.ts`).

### Names

- **Source:** the game's English locale files `core.cfg`, `base.cfg`, `elevated-rails.cfg`, `quality.cfg`, `recycler.cfg` and `space-age.cfg` (`data/<mod>/locale/en/` in the game folder). The copies used are in `2_detecting changes (simple)/data/en/` of [Midnighttigger/en-gb](https://github.com/Midnighttigger/en-gb) at commit `87230a029a62ff0e9086617ffed35fa5626c720b` (2026-10-06); the repository's `commands.txt` copies them unchanged from a Steam install. The game version isn't stated; the files include 2.1's `recycler` mod.
- **Terms:** © Wube Software. The repository is released into the public domain (Unlicense) for its own work, which doesn't extend to the game's files.

## Icons (`icons/`)

303 icons: every item and every building in the pack except the Pistol (which only its own recycling recipe deals with). They are Wube's images, converted to 64×64 WebP by `pnpm pack:import` (sharp: quality 85).

- **Source:** the sprite sheet `public/data/2x1/icons.webp` (2044×1978 px, SHA-256 `19cbbc78f272b1c70cbc4389f1875f81bdf63b61bfededc3420b506ae8f7643e`, 64×64 icons with 2 px gaps; positions in `public/data/2x1/data.json`) of FactorioLab's Factorio 2.1.20 with Space Age data set, in [factoriolab/factoriolab](https://github.com/factoriolab/factoriolab) at commit `eef44c6be28e251a22a211c2302ed43368d09ed0` (2026-10-21). `scripts/factoriolab-icons.ts` cuts it into one PNG per prototype name. FactorioLab builds its sheets from the game's icons, with layered icons (barrels) composed.
- **Terms:** © Wube Software. The repository's MIT licence (© 2020-2026 Doug Broad) covers its code; it says nothing about the game's images and doesn't restrict their reuse.

## Sources we didn't use

- `assets/data-raw-dump.json` in [cyx2015s/metatorio-calc](https://github.com/cyx2015s/metatorio-calc) at commit `960d980e7cc7c705ba4a3dd4be6422f6eb594474`: a 2.1 Space Age dump in the game's own formatting, but it doesn't say which version; we took the documented 2.1.14 one.
- `data/<mod>/locale/en/*.cfg` in [smanx/factory-web](https://github.com/smanx/factory-web): the same locale files, without a note on where they came from.
- [wube/factorio-data](https://github.com/wube/factorio-data) has the prototypes as Lua, but no locale, no graphics and nothing the game computes at load time; we used it only to check numbers.
- We found no Factorio 2.0 `--dump-data` output in a public repository, so the pack holds 2.1, the current version; the importer also reads 2.0 dumps.
- We skipped no source because of its licence: none of the above restricts reusing the game's images or data beyond Wube's own rights.
