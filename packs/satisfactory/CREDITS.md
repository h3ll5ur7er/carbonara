## Game data (`data/`)

Generated by the pack's importer (`plugin/importer.ts`) from the game's own data file.

### Items, buildings, recipes, alternates, generator fuels, belts and pipelines

- **Source:** Satisfactory **1.1**, `CommunityResources/Docs/en-US.json` (UTF-16, 10,066,644 bytes; it contains the Personal Elevator, which 1.1 added). We have no game install; the copy used is `src/SatisfactoryManager.Module.Core/Data/en-US.json` in [Melethainiel/SatisfactoryManager.Module.Core](https://github.com/Melethainiel/SatisfactoryManager.Module.Core) at commit `b96977a4b55e48dcda24eded18d85cb66160944a` (2025-09-06), an unmodified copy of the game file.
- **Terms:** © Coffee Stain Studios. The game ships the file for the community's tools but with no explicit licence. The repository it was taken from has no licence file.
- **In this repository:** only the generated data and a small excerpt of the file, as the importer's test fixture (`plugin/importer.fixture.ts`).

### Resource limits (`resources[].limit`)

- **Source:** `Data.resourceAmounts` in `src/Data/Data.ts` of [greeny/SatisfactoryTools](https://github.com/greeny/SatisfactoryTools) at commit `fb43f813c03eb306b0e8d0047a8c53ae010044e0`: the most each resource yields per minute on the whole map, the values it uses for 1.0 and later (not re-checked against the 1.1 map). The game's data file has no resource node data.
- **Terms:** the repository's code is MIT, © 2019 greeny. The numbers are facts about the game; we copied only the 12 numbers, into `MAP_LIMITS` in `plugin/importer.ts`.

## Game rules (`plugin/mechanics.ts`)

- **Source:** the same `en-US.json` (Satisfactory 1.1): the clock limits (`mMinPotential`, `mMaxPotential`), the Power Shard's `mExtraPotential` and the Somersloop's `mExtraProductionBoost`, each production building's `mProductionShardSlotSize` and `mProductionShardBoostMultiplier`, and the power exponents `mPowerConsumptionExponent` (1.321929) and `mProductionBoostPowerConsumptionExponent` (2). The Satisfactory Wiki's "Clock speed" page gives the same curve (1.321928, log2 2.5, since 1.0). The Smelter's one somersloop slot is from the game itself (Docs lists 0).
- **Terms:** facts about the game; only the numbers are used, in code.

## Icons (`icons/`)

All icons are Coffee Stain Studios' images, converted to 64×64 WebP by `pnpm pack:import` (sharp: resized to fit, transparent padding, quality 85). We took them from the community repositories below because we have no game install. None of those repositories owns the images or grants rights to them.

### 167 of the 168 item icons (every item but the Portable Miner)

- **Source:** `public/img/icons/IconDesc_*.png` and the fluid icons next to them (`LiquidWater_Pipe_256.png` …), at 256×256 (four at 512×512), in [NicholasJohn16/satisflow](https://github.com/NicholasJohn16/satisflow) at commit `dcba73b6efc631301cfc69c5677d3127baa69476` (2026-08-17). Its README says they were extracted from the game files with FModel. The file names are the game's texture names, which the importer matches against the items' `mSmallIcon`.
- **Terms:** © Coffee Stain Studios. The repository has no licence file.

### The Portable Miner icon

- **Source:** `assets/icons/IconDesc_PortableMiner_64.png` (64×64) in [adepierre/ficsit-companion](https://github.com/adepierre/ficsit-companion) at commit `d5c449adebe335cf326b6cb2d49c106888fc06c8` (2026-06-14).
- **Terms:** © Coffee Stain Studios. The repository's README says "All images comes from Satisfactory and are Coffee Stain Studios intellectual property"; its MIT licence covers the code, not the images.

### 19 of the 21 building icons

None yet for the Biomass Burner and the Resource Well Extractor.

- **Source:** `public/img/<Building_Name>.png` (300×300 or 512×512) in [NicholasJohn16/satisflow](https://github.com/NicholasJohn16/satisflow) at the same commit. The repository doesn't say where they came from; their names match the Satisfactory Wiki's image file names.
