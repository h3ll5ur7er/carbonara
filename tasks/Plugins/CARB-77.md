Follow-up of [[CARB-44]]. The Factorio pack has no power-generation buildings yet, and temperatures change no rates today.

- [x] Boilers, steam engines and turbines, with steam variants by temperature
- [x] Reactors with the neighbour bonus, heat exchangers (a node field, not a custom node kind: no compiler work)
- [x] Fusion
- [x] Fuel as an input of burner buildings (shared with [[CARB-78]])
- [x] The planner plans with recipes as nodes run them, so it supplies the fuel the plugin adds

Solar panels, accumulators and lightning are [[CARB-110]].

## Decisions

- **Generation is recipes, generated by the importer**, one second long per building: `boiler-steam`, `heat-exchanger-steam`, `nuclear-reactor-heat`, `heating-tower-heat`, `fusion-reactor-plasma`, `steam-engine-electricity@165` … `fusion-generator-electricity`. No new node kind, no contract change: the compiler, the solver and the planner treat a power plant like any other production line.
- **Electricity and heat are items** (`electricity`, `heat`, 1/s = 1 MW), not metrics, so a sink with a target sizes a power plant and the planner can plan "100 MW". Consumers keep reporting their use as the `power` metric; linking use and generation would add an electricity input to every node and is left out.
- **Temperatures are item variants** (`steam@165`, `steam@500`, `fusion-plasma@1000000` … `@9000000`), only for fluids generators burn for their heat. Recipes that take any steam come once per variant (`coal-liquefaction@165`/`@500`). Pack version 2.0.0, since `steam`, `coal-liquefaction` and `steam-condensation` are gone.
- **Fuel is a node field** (`fuel`, the building's first fuel, coal where it takes coal, by default) and an input `effectiveRecipe` adds (with burnt fuel cells as an output), for crafting burners and generators alike. One mechanism, and a stone furnace doesn't need a recipe per fuel.
- **Neighbour bonus is a node field** (`neighbours`): nuclear 0–4, an array's average (heat adds up); fusion 0–8 whole, since it picks the plasma variant. A fusion generator's `plasma` field says which temperature it takes; hotter plasma, less of it, as much coolant back.
- **The planner probes** the recipes as nodes run them (one compile of a node per allowed recipe, read back with every node running once), because a plugin can now add inputs; without it, plans of stone furnaces came out short of coal. See [[Architecture/Planning]].

## Verified numbers (reference factories in [[tools/pack-cli/factorio.mechanics.test.ts]])

One boiler (1.8 MW, 0.45 coal and 6 water a second) feeds two steam engines; a turbine makes 1.8 MW from 165 °C steam, 5.82 MW from 500 °C; a 2×2 reactor array makes 480 MW of heat from 0.02 cells/s, for 48 heat exchangers and 82.47 turbines; a heating tower 40 MW from 4 coal/s; one fusion reactor feeds two generators (100 MW), two linked ones eight (400 MW). Sources: the 2.1.14 Lua prototypes and the Factorio wiki, listed in `packs/factorio/CREDITS.md`.
